# 下午演示脚本（2026-11-12）

> 目标：让对面相信**这套东西不是"AI 随口推荐"，是一条能核对的推导链**。
> 时长：5–8 分钟。宁可少演两个动作，也不要在台上卡住。
> 服务：`http://127.0.0.1:7860`（只绑本机）。模型离线也能演，见 §5。

---

## 0. 演示前 4 件事（两分钟搞定）

1. 打开 `http://127.0.0.1:7860/api/health`，看到 `{"ok":true,"ollama":"0.40.16"}`
2. 先随便发一句预热（模型首次调用要 7 秒左右，别在台上等）：
   `学设计的，预算5100，要带去教室`
3. 侧边栏按投屏需要选一种：
   - 讲数据时**展开**（右侧 93/22/71 那张图就是卖点）
   - ⚠️ 2026-11-13 起右栏上半是「当前这台」，全库统计折在下面、**开聊后会自动收起一次**；
     讲数据前先点一下「全库统计」把它展开
   - 讲对话时点「收起 ⟩」把它收掉，对话区会自动居中、字更大
   - 也可以直接用 `http://127.0.0.1:7860/?rail=1`（收起）/ `?rail=0`（展开）
4. 记住一个应急链接：`http://127.0.0.1:7860/?q=<一句话>` 可以直接带问题进去，省得现场打字。

## 1. 开场 30 秒（不要先讲技术）

> "这不是排行榜，也不是比价器。它只做一件事：你说清预算和用途，它给你**一台具体机型**，
> 并且**它说的每一句都能追到数据**——追不到的，它会明说没有。"

指一下首屏那三个数：**93 台 / 22 台有人写过优缺点 / 4 类**。

> "93 台里只有 22 台有人逐台写过优缺点，剩下 71 台只有参数。
> 所以它不会对这 75 台说'值得买'——那是替人编评价。"

---

## 2. 六个动作（按顺序演，每个都有明确看点）

### 动作 ① 从零推荐：给出具体机型，先说短板

**输入**：`学设计的，预算5100，要带去教室`

**看点**：
- 直接给机型 + 到手价，不铺参数表
- 卡片上**先写"不算强"的那条**（屏幕素质），再说优点
- 下面是三台并列的对比表（价格/跑分/内存/重量/可加装）

**你可以说**：
> "注意它先说的是短板，不是优点。这行是它自己写的：屏幕素质同价位不算突出。"

---

### 动作 ② 追问细节：查不到就说查不到，并且告诉你下一步

**输入**：`屏幕怎么样`

**看点**：
- 只答屏幕，不把 CPU 内存硬盘念一遍
- 明说"这块屏我库里没人评过，我只报参数"

---

### 动作 ③ 问"这台行不行"：给判定，不换台

**输入**：`这台行不行`

**看点**：
- 直接给结论（匹配 / 部分匹配 / 不匹配 / 数据不足）
- 不会偷偷换一台更贵的

---

### 动作 ④ 专业路径（最能体现"有依据"）

**输入 1**：`计算机科学与技术专业，推荐一台`
→ 它会反问：笔记本还是台式

**输入 2**：`笔记本`
→ 追问预算

**输入 3**：`预算 8000 左右`

**看点**：
- 回答末尾带一段"按你的专业要求"：内存 16 起 / 32 推荐、内存要能加装（焊死等于四年没后路）
- 这台是否可加装、差几档，全部来自 `data/majors.json` 那张表

**你可以说**：
> "这段话不是模型想出来的，是专业配置表里写的原文。它先查表，再拿机器去对表。"

---

### 动作 ⑤ 要清单 / 要对比（证明它不会只会推一台）

**输入**：`把其余推荐列出来`
→ 输出第 2、3 名清单，每条都标"有没有人写过优缺点"

**输入**：`把它和另外两台放一起比`
→ 三台并列，缺数据的写"库里没记"，不补 0

---

### 动作 ⑥ 边界：它敢说"不"（收尾用这个最有说服力）

**输入**：`推荐个手机`
→ 明确拒答：只做 Windows 笔记本 / 台式整机 / 内存固态

**输入**：`预算 7000，学设计，还想打游戏`
→ 会先说清冲突：7k 的轻薄本没有独显，打游戏这条满足不了，问你要不要换游戏本

**你可以说**：
> "它最值钱的不是答得多，是**该说没有的时候说没有**。"

## 3. 万一被问到的问题（提前准备）

| 对方可能问 | 怎么答 |
|---|---|
| 数据哪来的、什么时候的 | 京东人工核对 22 台 + 采集 75 台，快照 2026-11-02，页面右上角一直显示 |
| 会不会瞎编参数 | 出口有审计：编造数字、库外机型、无出处评价都会被拦，编辑器里 `audit_data` 0 条 |
| 为什么只有 97 台 | 宁可少而准。淘宝 145 条价格口径不可信，明确不参与排序 |
| 推荐错了怎么办 | 它不给"综合评分"，只给可核对的字段；不满意可以问"换一台"或指定条件 |

## 4. 台上不要做的事

- **不要现场改数据文件**（`data/*.json` 是零写权限，改了就是事故）
- 不要连点发送（同一句话重复问，会走到"条件没改"的兜底，看起来像卡住）
- 不要问库外的东西（手机、平板、Mac），它只会拒答——除非你就是想展示拒答
- 不要承诺"它能告诉你帧数/续航/返修率"——这三样库里没有，它只会说没有

---

## 5. 兜底方案（模型挂了也能演）

1. `http://127.0.0.1:7860/api/health` 返回 `ok:false` → 模型离线
2. 页面仍可用：推荐走模板回答（语气干一点，但数字、短板、拒答全部正常）
3. 说一句："模型这会儿没起来，先用规则版给你们看推导链——数字是一样的。"
4. 若整页打不开：`cd E:\电脑涨价分析\tools\agent && python server.py`，重新起服务（7860）
