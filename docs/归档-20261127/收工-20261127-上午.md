## 这轮踩的新坑

### ① heredoc 把文件截成 0 字节

PowerShell `@"..."@` 传含特殊字符的 Python 代码，写文件失败把
`build_pc.py` 截成 0 字节。git checkout 恢复后重放改动。

**新铁律：改代码一律写临时 .py 脚本执行，不走 heredoc。**

### ② 比例劫持（修独显时三次失败）

```
第一轮  只强制配独显       → RTX 3050（dev 的 gpu 权重才 0.24）
第二轮  抬权重+归一化      → 总价 ¥13,827（超 73%）
第二轮半 事后降档          → 主板降到 AMD 平台，破坏兼容性！
第三轮  固定 0.5 + 硬上限  → 但 gaming 场景被劫持，整单 None！
第四轮  条件判断（<0.35 才抬）→ 全场景正确 ✓
```

**教训：gaming 本来就重显卡，显式独显对它是「确认」不是「抬档」。
只有原本不配独显的用途，显式要求才意味着改分配。**

### ③ CSS 重构的经典陷阱

重写 style.css 时删掉了 app.js 生成的旧 class 样式（.sec/.ubb/.cmp/
.md-table-wrap 等 40+ 个）——JS 零改动，但样式层断了。

**教训：重构 CSS 前先 grep JS 生成的全部 class，列清单逐个核对。**
（清单已写进 AGENT_HANDOFF.md 第六节）
