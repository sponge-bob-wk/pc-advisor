## 二、三个数据 bug（都不是模型问题）

### bug 1：60 条 unknown 样本白丢一次

我把手写的 60 条 unknown 样本**直接追加进 `route-train.jsonl`**（产物文件），
跑 `build_route_lora.py --write` 重新生成时被覆盖 → unknown 147 → 95。

修法：写成独立源文件 `unknown-expand-20261127.jsonl`，加进 `_NEW_EXTRA`
（不走 seed_rebalance —— 这批价值在句子形态，随机降采样会削掉要补的形态）。

### bug 2：SOURCES 有两处定义

```
L53   SOURCES = [14 个原始源文件]
L185  SOURCES = [("route-balanced.jsonl", ...)] + _NEW_EXTRA   ← 覆盖了上面
```

`route-balanced.jsonl` 是重采样成品，已包含全部原始数据。
**改 L53 等于没改** —— 第一次白改一次。

### bug 3：训练前 prompt 检查误报（差点拦住训练）

检查要求「训练集第一条 system == 固定 ctx 渲染结果」，但：
- `_sys_prompt()` 是**按每行 focus 状态**生成 ctx 的（806 / 728 两种合法变体）
- `SYS_TMPL` 的 JSON 部分是 `{{...}}` format 转义，必须 `format()` 后才能比

修法：改成「模板骨架 + ctx 形态」两级校验。

## 三、最难的 bug：保持集测出 35.3% 是假象

**现象**：v9 在 163 条保持集上 analyze 只有 6/17（35.3%）。

**排查了两小时，排除了**：

| 假设 | 验证结果 |
|---|---|
| prompt 不一致 | 逐字节对比：728 字符完全相同 |
| token 不同 | 完全相同的 335 个 token |
| max_new_tokens 影响 | 48 / 64 结果一致 |
| 批量推理状态漂移 | 连续跑 3 轮、跑 80 条后仍全对 |
| adapter 没加载 | 504 个 lora 参数、权重非零 |
| 模型能力不足 | **纯基座也能答对**（说明这题不难） |

**真正原因**：保持集 163 条里 **63 条 system prompt 是旧版**。

```
281 字符（旧版，topic 只 5 个选项）：42 条
806 字符（旧版带焦点）：21 条
728 字符（和推理一致）：100 条

17 条 analyze 里：
  281 字符的 11 条 → 全错
  728 字符的 6 条  → 全对
```

完全吻合。是我补保持集时**手写样本复制了旧模板** —— 测试标准不一致，不是模型问题。

修完重评：**analyze 35.3% → 100%**，总体 **87.1% → 93.3%**。

**教训**：保持集的 system prompt 必须和推理时**逐字节一致**，
不能"看着差不多"就复制。这和训练集那条铁律是同一个道理。

## 四、修了 5 条规则（模型泛化不足的兜底）

| # | 规则 | 解决的错例 | 提升 |
|---|---|---|---|
| 1 | 价位 + 要成品（配/装/主机）= state_new_need | 「五千配电脑」判 state_range | +22.7 点 |
| 2 | 价位 + 品类 + 求推荐 = state_new_need | 「笔记本推荐预算8千」 | 含在上面 |
| 3 | 看看/点评/修改 + 配置 = ask_current | 「求大佬看看配置」 | ask_current 66.7→85.7% |
| 4 | 复数词要清单 / 换台语气换台 | 7 条歧义句 | list_others 66.7→94.4% |
| 5 | 统计问法优先于"要更多" | 「五千以下有几台」vs「还有几个能选」 | analyze 82.4→88.2% |

**第 5 条踩了两次坑**：
- 第一次：`(几|多)(个|台|款)` 把「游戏本一共几台」也吃进 list_others
- 第二次：`_COUNT_ASK` 里裸的「几个」把「还有几个能选」吃掉
- 最终判据：**统计 = 「有/一共/多少」+ 数量词；要更多 = 「还/再/多」+ 数量词**

## 六、为什么不再训一次

剩余 11 条错例的分析：

```
别的牌子有吗      训练集同类 21 条，模型见过仍判错 → 语义歧义
再推荐几个        同类 17 条 → 同上
不要联想          同类 13 条 → 同上
就一台啊          同类 0 条  → 真缺，但只 1 条
还有吗还有吗      同类 0 条  → 真缺，但只 1 条
```

**7/11 是"见过同类但判错"** —— 这是**语义本身有歧义**，不是数据不足：
> 「别的牌子有吗」既能理解成"换一台"，也能理解成"列一下其他牌子"，两种都合理。

加数据解决不了，**规则解决得了**（已做）。

## 七、部署踩的坑

服务会静默回退到 `agent.py` 默认的 `route-v6-q8`（不是刚训的 v9）。

必须在 PowerShell 里先设：
```powershell
$env:MODEL='route-v9-q8'
python restart_public.py
```

判断是否生效：看 `_server.log` 里的 `模型 route-v9-q8 @ ...` 那行。
