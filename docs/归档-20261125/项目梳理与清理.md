### 1.2 `run_all_tests.py` 漏注册 5 个测试（真缺陷）

**发现过程**：核对 README 时发现「测试文件 25 个，但 run_all_tests 只注册 18 个」。

**查下来**：

```
未注册的 7 个：
  test_attack   ~ test_attack5   ← 还能跑！实测 test_attack 有 29 条攻击
  test_compress2 / test_compress_prompt  ← 我昨天的临时工具
```

**为什么漏了**：八轮对抗测试的汇总行**各写各的格式**：

| 测试 | 汇总格式 |
|---|---|
| `test_attack` | `攻击 29 条，硬问题 2 条，可接受项 2 条` |
| `test_attack2` | `第二轮攻击：通过 25/30` |
| `test_attack3/4/5` | `第三轮攻击：全部通过` / `失败 3 条 → xxx` |

原来的解析器只认 `通过 N/M` 和 `违规 N/M`，所以这 5 个测试的输出来就解析不了，
当初干脆没注册。

**代价：1300 多行测试从来没进过回归。**

### 2.2 扩展解析规则（4 种新格式）

```python
# 「攻击 29 条，硬问题 2 条」→ 通过 27/29
m = re.search(r"攻击\s*(\d+)\s*条[，,]\s*硬问题\s*(\d+)\s*条", out)
if m:
    n, hard = int(m.group(1)), int(m.group(2))
    return n - hard, n, "攻击 %d（硬问题 %d）" % (n, hard)

# 「第 N 轮攻击：全部通过」→ 用 exit code 判定
if re.search(r"第[一二三四五六七八]轮攻击：全部通过", out):
    return None, None, "全部通过"

# 「第 N 轮攻击：失败 M 条」
m = re.search(r"第[一二三四五六七八]轮攻击：失败\s*(\d+)\s*条", out)
if m:
    return None, None, "失败 %s 条" % m.group(1)
```

**验证**：

| 输入 | 解析结果 |
|---|---|
| `攻击 29 条，硬问题 2 条，可接受项 2 条` | `(27, 29, '攻击 29（硬问题 2）')` ✓ |
| `第二轮攻击：通过 25/30` | `(25, 30, '通过 N/M')` ✓ |
| `第三轮攻击：全部通过` | `(None, None, '全部通过')` ✓ |
| `第四轮攻击：失败 3 条 → xxx` | `(None, None, '失败 3 条')` ✓ |
