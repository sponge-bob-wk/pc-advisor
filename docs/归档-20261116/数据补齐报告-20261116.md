## 1. 根因：不是没爬到，是解析丢了

`tools/zol_fetch.py` 的注释里写着一句断言：

> 「ZOL 参数表**没有** CPU型号 / 内存容量 / 硬盘容量 / 分辨率 这四项，
> 它们只在页面标题的型号串里……」

**这句话是错的。** 实测参数页 56 个字段里这些全都有，而且是结构化的：

```
CPU型号      = Intel 酷睿 Ultra 7 255HX
核心/线程数   = 20核心/20线程
功耗         = 55W
内存容量      = 16GB
插槽数量      = 2xSO-DIMM
最大内存容量   = 64GB
硬盘容量      = 1TB
显卡芯片      = NVIDIA GeForce RTX 5060
显存容量      = 8GB
显卡最高功耗   = 115W
屏幕分辨率     = 2560x1600
数据接口      = 1×全功能USB3.1 Type-C，1×USB 3.1，2×USB 3.0
```

从标题型号串抠的后果：`gpu` 只有型号没有显存、`cpu.cores` 全空、
`gpu.tgpMaxW` 全空 —— 这正是 243 台池子里 cores 缺 163 台、vramGB 缺 167 台的直接原因。

**数据其实早就爬回来了，在解析那一步被丢掉了。**

## 4. 价格：一台都没补上（这是硬边界，不是没做）

**目标**：163 台 ZOL 机器的 `price.net` / `price.final` / `price.subsidy`。

**实测结果**：
- `p.3.cn/prices/mgets`（京东价格 API）→ 连接超时
- `item-soa.jd.com/getWareBusiness` → 返回风控页，正文含「风险」
- `item.jd.com` PC 页 → 35KB 空壳，价格由异步接口渲染
- `search.jd.com` → 直接重定向 `risk_handler`（与 AGENTS.md §8.9 记录一致）
- `item.m.jd.com` 移动页 → **能打开 248KB**，能读到店铺名（「联想京东自营旗舰店」），
  但价格字段是 `"price":"1"` 占位 —— **需登录才下发真实价**
- ZOL detail 页的「￥9449」之类 → **全是「相关产品」里竞品的价格**
  （每条都带 `interest-compare` 和别的机型 id），是 `zol_fetch.py` 警告过的陷阱

**所以只做到了两件**：
1. `price.list` 补 1 台（其余本来就有）；
2. `priceSnapshots` 记了 54 台的 ZOL 京东/天猫快照价（**单独存放，不进 price 口径**）。

**为什么不把 ZOL 快照写进 `net`/`final`**：
项目口径里 `net` 是算涨幅的唯一依据。ZOL 的「电商报价」是平台标价快照，
不含国补、不含券、不保证实时。写进去会直接污染「电脑涨价分析」这个项目的核心指标，
属于最坏的一类错误（数字看着像真的，口径却是另一个）。

**要继续补，需要你提供**：已登录的 Edge/Chrome 会话（AGENTS.md §8.9 的正确做法），
或者你手动把商品页打开、我接管截图读价。

### 4.1 能效网：本地台账匹配上了 11 台，在线查询需要登录

`efficiency` 缺 173 → **162 台**，`certModel` 缺 232 → **192 台**。

**做了两件事**：

1. **`match_energy_from_params.py`** —— 用 ZOL 参数页的 `产品型号`（如 `am2071TX`、
   `LEGION R7000P ADR10`）去 `efficiency_ledger.json` 的 186 条备案里做**精确匹配**，
   命中 **11 台**，全部带备案号与生产商：
   ```
   zol-2137419~16  联想拯救者R7000P    LEGION R7000P ADR10  1级  20251211-CEL0272025-378760
   zol-2168787     联想小新Air         小新Air 15 IWC11     1级  20260417-CEL0272025-912516
   zol-2161082     联想小新Pro14       小新Pro 14 IPH11     1级  20251217-CEL0272025-008379
   zol-2161087     联想YOGA Pro        YOGA Pro 15 IPH11    1级  20260108-CEL0272025-390624
   zol-2128701     联想拯救者Y9000P      LEGION Y9000P IAX10  1级  20251216-CEL0272025-362868
   zol-2175977/78  联想小新Pro14        小新Pro 14c AHP10R   1级  20251205-CEL0272025-252739
   ...
   ```
   ⚠️ 每台都写了 `efficiencyBasis`：**能效备案按「型号码」登记，同一型号码下的不同
   GPU 配置（R7000P 的 5050/5060/5070 三版）共用同一条备案**，属型号级匹配非遗 SKU 直读。
   `efficiency` 是 P 级字段，只影响国补金额，不影响判定结论，所以这个精度可接受。

2. **`fill_cert_model.py`** —— 把参数页的 `产品型号` 搬进 `certModel`，补了 **29 台**
   （如 `am2071TX`、`ku0023TU`、`X5HPNAG-A91`、`G835LW275-0ECAXHBAX30`）。
   **只写含 ASCII 字母的型号码，中文营销名一律跳过（67 台）** ——
   `efficiency_nodata.json` 里已记了一堆「用中文名查能效网 = 暂无数据」的白跑记录。

**在线查询为什么没做**：能效网是 Vue SPA，后端在 `/admin-api/`，实测：
```
GET https://www.energylabel.com.cn/admin-api/system/dict-data/list-all-simple
→ {"code":401,"data":null,"msg":"账号未登录"}
```
必须登录。这也解释了为什么仓库里 `energy_query.py` 走的是「Edge 无障碍树」而不是 HTTP ——
那条路需要你本机开着已登录的 Edge。

## 5. 没补的 147 对，逐项说明为什么停手

| 卡点 | 对数 | 为什么停 |
|---|---:|---|
| `ramType` | 44 | 需 `ram.form`。这 44 台里 **38 台页面只写 `DDR5`、13 台连内存类型都没有**，且无插槽数量、无「N GB × M 条」配置。DDR5 可以板载也可以插槽，**拿它推 sodimm 是错的**，宁可留空。ZOL 的 PC 参数页/detail 页/移动版、联想官网商品页**四处都实测没有插槽字段**。（另有 7 台手机，见下） |
| `ports` | 35 | 17 台拯救者页面只有「无线网卡/有线网卡」，无任何接口键。有「千兆以太网」能推 RJ45，但填了会让 `port_has(m,'usb-a')` 判 False → 报「没有 USB-A 需扩展坞」——把不知道说成缺，`lib_judge:416` 明令禁止 |
| `storageGB` | 36 | 5 台，其中 3 台是手机（见下），另 2 台页面硬盘字段只写协议不写容量 |
| `ramGB` | 35 | 同上 3 台手机 + 1 台 2015 年 Flex3 |
| `tgpW` | 22 | 12 台页面无「显卡最高功耗」键。「功耗 95W」是 **CPU** 功耗，不能冒充 |
| `vramGB` | 21 | 5 台，其中 3 台手机；华为两款折叠本是 HarmonyOS 统一内存，无独立显存 |
| `cpu.cores` | 10 | 8 台是手机；华为麒麟 X90 Plus / XE90 页面无核心数字段 |
| `colorGamut` | 5 | 页面确实没有色域字段 |

**`ram.form` 的四档证据**（`recover_ram_form.py`，共补 20 台）：
1. 「插槽数量 = 2xSO-DIMM / 板载 / 0」 —— 直读；
2. 「内存类型 = LPDDR*」 —— LPDDR 物理上全是板载封装；
3. 「内存配置 = 16GB×2」+ DDR —— 写了 ×N 就是 N 条物理模组，板载不会这么写；
4. 「最大内存容量 > 已装容量」 —— 否则怎么加。

**其余补不动的（也已实测确认是数据源边界）**：
- `batteryWh` 43 台：页面「电池类型」只写「4芯锂电池」，**没有瓦时数**，31 条全都解析不出 Wh；
- `weightKg` 41 台：页面无重量字段；
- `refreshHz` 42 台 / `brightnessNit` 96 台：页面无对应键（`亮度` 键缺失，不是解析漏）。

**另外 31 对是 7 台手机造成的虚高**：池子里混进了 `苹果iPhone`、`vivo`、`华为nova`、
`红米Redmi Note`、`华为 Pura X`（从 ZOL 列表页误采）。它们的「内存容量/硬盘容量」
是手机口径。**我没有删它们** —— 删数据要你拍板，只在映射脚本里跳过。
