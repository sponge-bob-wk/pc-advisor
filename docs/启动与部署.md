# 启动与部署 · 一页纸

> 双击就能用。不用记命令。

---

## 四个入口（项目根目录）

| 文件 | 干什么 | 什么时候用 |
|---|---|---|
| **启动助手.bat** | 打开菜单，选 3 种模式之一 | 日常，最常用 |
| **一键公网链接.bat** | 直接生成公网链接（跳过菜单） | 要给测试同学发链接时 |
| **停止服务.bat** | 停掉服务 + 隧道，释放 7860 | 用完、或端口被占 |
| **环境检查.bat** | 只检查不启动 | 启动失败时先跑这个 |

想要桌面图标：双击 `scripts\make-desktop-shortcut.bat`，会在桌面生成
「启动电脑选机助手」。**这个不会自动执行**，因为往桌面写东西需要你自己点头。

## 三种模式到底差在哪

| 模式 | 谁能打开 | 需要外网 | 链接会变吗 |
|---|---|---|---|
| **1 本机自用** | 只有这台电脑 | 不需要 | 不会 |
| **2 局域网共享** | 同一个 WiFi / 网线下的设备 | 不需要 | IP 变了才会变 |
| **3 公网测试链接** | 任何拿到链接的人 | 需要 | **每次重启都变** |

### 1 本机自用
```
http://127.0.0.1:7860/?k=dev123
```
自己调界面、试问题时用。只绑 `127.0.0.1`，别人连不上，最安全。

### 2 局域网共享
```
http://172.24.23.60:7860/?k=dev123     ← 这个 IP 是你的，每台机器不同
```
同组的人在同一个 WiFi 下就能打开。**不依赖外网**，公司网络/校园网也能用。
第一次启动时 Windows 防火墙可能弹窗，要选「允许」。

### 3 公网测试链接
```
https://xxxx-random-words.trycloudflare.com/?k=dev123
```
任何人拿到就能开。启动器会自动：
- 建隧道、等它真正登记完成
- 把链接拼好写进 `测试链接.txt`
- 复制到剪贴板（直接 Ctrl+V 就能发）

⚠️ **这个地址每次重启都会换**，不是固定的。因为用的是 Cloudflare 免费临时隧道。

## 启动时它替你检查什么

启动前会跑一遍，四项都过才启动：

```
✓ 程序文件在位        tools/agent/server.py 找得到
✓ Ollama 在线         11434 端口有响应
✓ 端口 7860 空闲      没被别的程序占着
✓ cloudflared 在位    （只有公网模式才查）
```

**Ollama 没开**是最常见的问题：网页能打开、界面能看，但每问一句都失败。
另开一个窗口运行 `ollama serve` 就行。

**端口被占**也不用管，启动器会问你要不要停掉占用的那个，选 Y 即可。

---

## 停止

三种方式，任选：

1. 双击 **停止服务.bat**
2. 在启动器窗口按 **Ctrl+C**
3. 启动器菜单选 **4**

停止脚本会把服务、隧道、以及所有残留的 cloudflared 一起清掉，
并且**验证 7860 真的释放了**才报成功。

> 为什么专门做这个：以前用 `start` 开窗口，关掉窗口后 python 有时
> 还占着 7860，下次启动就报 `Address already in use`。现在按 PID + 端口
> 双路清理。

## 命令行（不想用菜单时）

```bash
python tools/launcher.py           # 打开菜单
python tools/launcher.py local     # 本机
python tools/launcher.py lan       # 局域网
python tools/launcher.py public    # 公网链接
python tools/launcher.py stop      # 停止
python tools/launcher.py check     # 只检查
```

## 换端口 / 换访问码

改 `tools/launcher.py` 顶部：

```python
DEFAULT_PORT = 7860
DEFAULT_CODE = "dev123"
```

或者临时用环境变量：

```bash
set PORT=7861
set ACCESS_CODE=my-secret
启动助手.bat
```

## 常见故障

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 网页能开，一问就报错 | Ollama 没启动 | 另开窗口 `ollama serve` |
| `Address already in use` | 上次没停干净 | 双击 停止服务.bat |
| 公网链接打不开（Error 1033） | 隧道还没通 / 已断 | 等十几秒刷新；或重启 |
| 手机连不上局域网地址 | 防火墙拦了 | 允许 Python 通过防火墙 |
| 提示找不到 Python | 没加 PATH | 重装 Python 勾选 Add to PATH |
| 隧道建不起来 | 出不了外网的 443 | 用局域网模式，那个不依赖外网 |

---

## ⚠️ 最重要的一条

**公网模式下，你的电脑必须一直开着，不能睡眠。**

服务、模型、隧道全跑在这台机器上。关机 / 睡眠 / 关掉窗口，
链接立刻失效——测试同学那边看到的就是 Cloudflare 的错误页。

想让它长期在线，把电源设置改成「永不睡眠」，或者用台式机做服务器。
