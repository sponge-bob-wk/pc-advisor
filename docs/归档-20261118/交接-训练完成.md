| 加 `--resume` | 中断后从最新 checkpoint 续训，不用从头 |

## 4. 踩的三个坑（都记下来了）

### 坑 1：Ollama 占显存导致训练速度暴跌

训练到第 30 步时，速度从 8 秒/步掉到 **28 秒/步**，剩余时间从 25 分钟涨到 71 分钟。

查出来：

```
显存 7678 / 8188 MiB   ← 快满了，开始换页
llama-server.exe 还在跑 ← 之前起的 Ollama 服务没关
```

**关掉 Ollama 后速度回到 6.7 秒/步**（比基准还快，因为显存压力小了）。

**教训：训练前先关 Ollama。** 命令：

```powershell
Get-Process -Name 'llama-server','ollama' -ErrorAction SilentlyContinue |
    Stop-Process -Force
```

### 坑 2：日志编码 UTF-16 导致正则全失效

PowerShell 的 `Tee-Object` 默认写 **UTF-16 LE**（BOM `0xff 0xfe`），
而 `training_record.py` 用 `io.open(encoding="utf-8")` 读 —— 抛 `UnicodeDecodeError`。

**更坑的是**：`Get-Content` 能正常读（自动识别 BOM），所以 `Select-String` 看得到内容，
但 Python 读不到 —— 导致"可训练参数"永远显示 `—`，而且**不报错**。

修法：`_read_log_text()` 先看 BOM 判断编码，读不出来再逐个试。

### 坑 3：cmd 和 PowerShell 语法不同

用户在 **cmd.exe** 里敲 PowerShell 命令：

```cmd
> & 'E:\ai2026\Scripts\python.exe' watch_training.py --follow
此时不应有 &。

> 'E:\ai2026\Scripts\python.exe' watch_training.py --follow
文件名、目录名或卷标语法不正确。
```

**cmd 里正确的写法**：

```cmd
cd /d E:\电脑涨价分析\tools\agent
chcp 65001
"E:\ai2026\Scripts\python.exe" watch_training.py --follow
```

| 场景 | PowerShell | cmd.exe |
|---|---|---|
| 带空格路径 | `& 'E:\...'` | `"E:\..."` |
| 单引号 | ✅ | ❌ |
| `&` 调用符 | ✅ | ❌ |

## 5. 还没解决的（晚上做）

### P0：验证 corrections 的 CoT 是否有副作用

**问题**：7 条判错里 **4 条在训练集里出现过**（我收进 corrections 了）。
训练过还是错，说明两种可能：

1. 3 epoch 不足以改掉这个习惯
2. **corrections 的 CoT 反而干扰了** —— 它的 CoT 是"事后补的正确判据"，
   不是模型真实推理，可能让模型困惑

**实验设计**：

| 组 | 训练数据 | 预期 |
|---|---|---|
| A | 全量 490 条（当前） | 基线：对抗 86.0% |
| B | 剥掉 corrections 的 CoT | 如果更高，说明 CoT 有害 |
| C | 完全去掉 corrections | 如果更高，说明纠错样本本身有害 |

**判据**：对抗测试准确率 + 那 7 条判错能修好几条。

### P1：调学习率重训

用户观察到 loss 反复跳跃（中期 0.08~0.68 摆动）。判断是学习率偏高 + batch=1。

建议 `--lr 1e-4 --epochs 5`，预期曲线更平滑，精度可能更高。

### P2：模型对 `state_range` 有过度倾向

7 条判错里 **4 条判成 `state_range`**：

| 句子 | 期望 | 实际 |
|---|---|---|
| 预算卡死 6000 不能再高了 | `state_new_need` | `state_range` |
| 这台太重，找个轻的 | `refuse_switch` | `state_range` |
| 一次说完吧 | `list_others` | `state_range` |
| 再挑挑 | `refuse_switch` | `state_range` |
| 这个价位还有别的不 | `refuse_switch` | `state_range` |

需要扩充 `state_range` 的负样本（明确不是 state_range 的句子）。

**训练指标好 ≠ 实际对话好。** 要做的：
