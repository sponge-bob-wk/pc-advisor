# 启动器修复（2026-11-18 中午）

> 用户反馈三个问题：
> ① `启动助手.bat` 双击后浏览器访问不了
> ② Ollama 得手动启动
> ③ 三个 bat（启动/停止/一键公网）要查是不是真能一键用

---

## 一、诊断结果

三个 bat 都是薄壳，实际逻辑在 `tools/launcher.py`：

| bat | 传给 launcher.py 的参数 | 修复前状态 |
|---|---|---|
| `启动助手.bat` | （无）→ 交互菜单 | ⚠️ 能用但要选，且**不自动开浏览器** |
| `停止服务.bat` | `stop` | ⚠️ 停 server 但**不停 Ollama** |
| `一键公网链接.bat` | `public` | ✅ 能用（已验证起隧道成功） |

### 问题 1：启动后访问不了

**根因**：`run_local()` 只打印 URL，然后 `hold(proc)` 阻塞。
用户双击 bat 看到的是黑窗口，得自己复制 URL 去浏览器 —— 不会复制的人就以为"访问不了"。

**不是端口问题**，是**没自动打开浏览器**。

### 问题 2：Ollama 得手动启动

**根因**：`launcher.py` 原来**只检查不启动** Ollama。

```
检测到没跑 → 打印「另开一个窗口运行：ollama serve」
           → 问「还是要启动吗？[y/N]」
           → 用户直接回车（默认 N）→ 回菜单 → 服务没起来
```

这体验是错的：启动器就该把依赖拉起来，不该让用户开第二个窗口。

## 二、修了什么

### 2.1 加 `start_ollama()`：自动拉起

三种情况都处理：

| 情况 | 做法 |
|---|---|
| `ollama` 在 PATH | 起 `ollama serve` |
| 只有桌面版（托盘应用） | 起 `ollama app.exe`，它会带起后端 |
| 都找不到 | 返回失败，给明确指引 |

启动后**轮询等它就绪**（最多 40 秒），实测 **2.0 秒**就通了。

### 2.2 `run_local()` 自动打开浏览器

```python
time.sleep(1.0)          # 等 accept 循环真正就绪
webbrowser.open(url)
```

延迟 1 秒的原因：`wait_server()` 只测了端口能连，
第一帧可能还没准备好。

### 2.3 `stop_all()` 同时停 Ollama

原来只停 server + 隧道。现在加：

```python
for nm in ("ollama app", "ollama", "llama-server"):
    subprocess.run(["taskkill", "/F", "/IM", "%s.exe" % nm], ...)
```

**为什么要停 Ollama**：留着它占约 900MB 显存没意义。
实测过代价：训练时 Ollama 占着显存 → 速度从 8 秒/步掉到 28 秒/步。

## 三、踩的坑：tasklist 输出解析（改了两次才对）

这是本轮最花时间的部分。

### 第一次：取 `parts[1]` 当 PID

```
tasklist 输出：
  ollama app.exe    38756 Console    9    36,984 K
split() 后：
  parts[0]='ollama'  parts[1]='app.exe'  parts[2]='38756'
```

`parts[1]` 是 `'app.exe'`，`isdigit()` 失败 → **杀不掉 ollama app**
→ app 又把后端拉起来 → 死循环。

### 第二次：从后往前找纯数字

```python
pid = next((x for x in reversed(parts) if x.isdigit()), None)
```

这次取到了 **`9`**（Session# 那一列），杀了个不存在的 PID。

**根因**：`tasklist` 的列数不固定 ——
`Mem Usage` 可能带逗号、`Session Name` 可能是 `Services` 或 `Console`、
名字里可能有空格。**按位置解析必然出错。**

### 第三次（正确）：改用 `taskkill /IM`

```python
subprocess.run(["taskkill", "/F", "/IM", "%s.exe" % nm],
               capture_output=True, text=True, encoding="gbk", ...)
```

**按映像名杀，不关心 PID**，名字带空格也没问题（用列表参数传，不拼字符串）。

从输出里抠 PID 只为打印：

```python
m = re.search(r"PID\s+(\d+)", r.stdout or "")
```

### 还有一个顺序坑

**必须先杀 `ollama app`（托盘程序），再杀后端。**
反过来的话 app 会立刻把 `ollama`/`llama-server` 重新拉起来。

实测：杀完 ollama 后 1 秒内 11434 又通了。

## 五、一个不是 bug 的现象

测试时看到：

```
[服务] Exception occurred during processing of request
[服务] ConnectionAbortedError: [WinError 10053]
```

**这是测试客户端主动断开导致的**（我用 Start-Job 跑完就杀了），
不是服务端问题。真实浏览器访问不会出现。

## 六、访问码说明（避免下次困惑）

首页 `/` 不需要访问码，**API 需要**：

```
http://127.0.0.1:7860/?k=dev123        ← 带码的完整地址
X-Access-Code: dev123                  ← 或者放请求头
```

启动器打印的 URL 已经带了 `?k=dev123`，所以正常点开就能用。

**如果手动测 API 忘了带码，会得到 401** —— 那是设计如此，不是故障。

## 七、三个 bat 现在的状态

| bat | 状态 | 说明 |
|---|---|---|
| `启动助手.bat` | ✅ | 双击 → 选 1 → 自动启 Ollama + 开浏览器 |
| `停止服务.bat` | ✅ | 双击 → 停 server + 隧道 + Ollama，端口全释放 |
| `一键公网链接.bat` | ✅ | 双击 → 起服务 + Cloudflare 隧道，给出公网链接 |

**注意**：`启动助手.bat` 仍会进交互菜单（这是设计，因为要选本机/局域网/公网）。
如果想要"双击直接本机启动"，可以新建一个 bat 传 `local` 参数：

```bat
@echo off
call "%~dp0scripts\launcher.bat" local
```

## 八、给下一个接手者

1. **杀 Ollama 用 `taskkill /IM`，不要解析 `tasklist`** ——
   那个输出列数不固定，按位置解析必然错（我改了两次）。
2. **先杀 `ollama app` 再杀后端** —— 顺序反了会被重拉。
3. **测 API 记得带 `X-Access-Code: dev123`** —— 不带会 401。
4. **`ConnectionAbortedError` 通常是客户端断开**，不是服务端 bug。
