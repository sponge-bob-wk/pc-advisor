### 3. 修「问细节却回头问槽位」

```python
agent.run('有别的颜色吗', focus='zol-2130961')
# 修前 → clarify「是笔记本还是台式？」
# 修后 → followup「这台只有雾屿白一种颜色」
```

根因：`focus` 只带 id 不带槽位，`missing_required(slots)` 缺「品类」触发 clarify。

修法：有 focus + 在问这台的某一面 → 直接答细节，跳过槽位收集。
