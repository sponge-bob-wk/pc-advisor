# 功耗数据：从"完全没有"到"有上下界"（2026-11-17 晚）

> 起因：修「限电 500W」时一直以为库里没有功耗数据，
> 所以模型只能推测，被审计拦掉后干脆不提。
>
> 扫了一遍参数页才发现：**88 台有「功耗」字段**。
> 但**它不是整机功耗**，是 CPU TDP —— 差点写错。

---

## 1. 发现：参数页里确实有功耗数据

```python
# data/zol/params-2026-11-16.jsonl 的键覆盖
功耗           88 台    ← 一直以为没有
显卡最高功耗    46 台
电源适配器      123 台
电池容量         5 台
续航时间        84 台
```

第一反应：太好了，「限电 500W 够不够」终于能真答了。

---

## 2. 差点犯的错：把 CPU TDP 当成整机功耗

差点把「功耗」直接存成 `powerW`（整机功耗）。验证时发现不对：

```
zol-2128664 惠普暗影精灵11
  功耗        = 55W      ← 这个
  电源适配器   = 230W
  显卡最高功耗 = 115W
```

**CPU 55W + 显卡 115W = 170W，再加主板/内存/屏幕/风扇，
整机绝不可能只有 55W。**

55W 是 i9-14900HX 的 TDP。

### 如果写错了会怎样

字段叫 `powerW`，上层就会说「整机 55W，限电 500W 绰绰有余」——
用户真按这个买，宿舍直接跳闸。

**这个错误比"没有数据"危险得多**：没有数据时用户会自己去查，
有错误数据时用户会信。

### 修法：字段名必须体现语义

```python
patch["cpu.tdpW"] = 55        # ✅ 明确是 CPU TDP
patch["gpu.tgpMaxW"] = 115    # ✅ 显卡 TGP
# 不许叫 powerW —— 库里没有整机功耗
```

---

## 3. 能算出来的：上下界

有了 `cpu.tdpW` 和 `gpu.tgpMaxW`，能给出一个**区间**：

| 边界 | 怎么算 | 含义 |
|---|---|---|
| **下界** | CPU TDP + GPU TGP | 核心部件最小消耗，不含主板/内存/屏幕 |
| **上界** | 适配器标称功率 | 电源最多能给这么多 |

判据：

```
下界 > 限电  → 明确不够（下界都超了，实际更超）
下界 ≤ 限电  → 只能说"下界没超"，不能保证够
```

### 实测回答

```
U: 限电 500W 这台够用吗（惠普暗影精灵11）

A: …就你的用途看，匹配。…
   关于限电：CPU 55W + 显卡 115W，加起来 170W 是**下界**（不含主板/内存/屏幕）；
   下界没超限电 500W，但整机实际功耗会更高，够不够我判断不了；
   标配 230W 适配器（适配器标称，是上界参考，不是实际功耗）；
   要确切数字得看厂商规格页的「功耗」栏，或问客服要满载功耗。
```

**四句话全是实话**：下界 170W、上界 230W、判断不了、指路。

## 5. 关键教训：字段名就是契约

这轮如果图省事写成 `powerW`，后果是：

- 上层会当整机功耗用
- 用户看到"整机 55W"，以为限电 500W 绰绰有余
- 实际满载 200W+，宿舍跳闸

**教训：数据字段名必须体现"这是什么"，不能体现"我想让它是什么"。**

同类风险清单（值得复查）：

| 字段 | 有没有可能被误解 |
|---|---|
| `adapterW` | ✅ 名字明确是适配器 |
| `cpu.tdpW` | ✅ 明确是 CPU |
| `gpu.tgpMaxW` | ✅ 明确是 GPU |
| `weightKg` | ✅ 明确是 kg |
| `batteryLifeH` | ⚠️ 厂商标称续航，水分大，名字没说 |
| `powerText` | ❌ 已删（本来想存原始文本） |

## 7. 下一步

### P1：整机功耗还是缺

`cpu.tdpW + gpu.tgpMaxW` 是**下界**，不是实际值。
真正的整机功耗要查厂商规格页（"典型功耗""最大功耗"），
或评测实测（Notebookcheck 有功耗测试数据）。

### P2：`batteryLifeH` 的语义要标清

它是「厂商标称续航」，不是实测。用户问"能用多久"时
应该说"厂商标称 X 小时"，不能说"能用 X 小时"。

### P3：`batteryWh` 只有 5 台

参数页的「电池容量」覆盖率很低。可以从「电池类型」里抠
（154 台有），或者查厂商规格页。
