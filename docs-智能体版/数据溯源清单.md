# 数据溯源清单

> 生成于 2026-11-11。这份文件回答一个问题：**`prices.json` 里每个数字，到底是怎么来的。**

---

## 1. 采集方式（三种，可靠性完全不同）

| 方式 | 怎么做 | 拿到什么 | 可靠性 |
|---|---|---|---|
| **A. 跑分聚合站** | 搜 cpu-monkey / Notebookcheck / NanoReview 等 | CPU 双跑分、GPU Time Spy 分数 | 中。**是二手聚合，不是我们实测** |
| **B. 京东商品页摘要** | 搜索索引里返回的京东商品卡（价格/配置/重量/屏幕/电池） | 商品规格与页面价 | 较高。字段来自商品页，但**不是实时价，可能有数天延迟** |
| **C. 评测文章 / 选购清单** | ZOL、IT之家、PChome、什么值得买等 | 实测跑分、到手价、优缺点素材 | 中。**单机实测，换台机器可能不同** |

**必须说明的一点**：所谓「实测换算」，指的是**换算依据是公开评测跑分**，不是我们自己在每台机器上跑的分。同一颗 CPU 在不同机器上因散热和功耗墙，实测能差 5~15%。

## 3. 已发现并修正的错误

### R7 H255 的 R23 单核（2026-11-11 修正）

| 来源 | 单核 | 多核 |
|---|---|---|
| 百度百科 | **2055** | 16887 |
| PChome 实测 | 1709 | **15475** |
| minipc-review | ~1750 | 15800~16300 |
| geekchamp | 1750~1900 | 15000~18000 |

原数据 **2055 / 15475** —— 单核取了百度百科的异常高值，多核取自 PChome，**两个来源拼在一起**。

已改为 PChome 同一台机器的完整实测 **1709 / 15475**。性能分从 62 降到 55，影响 5 台机型。

**教训**：跨来源拼数字是最隐蔽的错误。它不会让某个数明显荒谬，但会让两个数不属于同一个测试条件。

## 5. 价格溯源

| 状态 | 数量 | 含义 |
|---|---|---|
| `verified` | 12 | **搜到了京东商品页摘要**（价格、配置、店铺都对得上） |
| `reported` | 16 | 来自选购清单或销量榜的「国补后参考价」，**未逐台核京东页面** |
| `pending` | 8 | 没查到，留空不编 |

**`verified` 不等于实时价。** 它是搜索索引里的商品页快照，可能延迟数天。真正下单前必须自己看页面。

**同一 SKU 会有 3 个数**（`priceList` / `price` / `priceBest`），因为地区补贴、优惠券、PLUS 会员、店铺都影响最终价。战 66 实测：标价 5799、常规 5749、国补后 4674。

## 6. 优缺点（pros / cons）——最不可信的一层

这一层**没有数据来源**，是我根据：
- 跑分与价格的对比
- 商品页的规格短板（如 45% NTSC 低色域屏）
- 已知的行业问题（低温锡虚焊、Linux 版需预装 Windows）

**写的编辑判断。**

它属于「有依据的观点」，不是「事实」。产品里必须这样标注，不能让用户以为是数据。

## 7. 根本问题与修复方向

### 问题一：没有字段级溯源

`prices.json` 里有 13 条 `sources`，但**没有记录哪台机器的哪个数字来自哪条来源**。所以出现 R7 H255 那种跨来源拼接时，没有任何机制能发现。

**修复**：给跑分加 `cb23Source` / `gb6Source` 字段（R7 H255 已加），价格已经有 `priceNote` 和 `channel`。

### 问题二：没有统一取数规则

同一次采集里，有的取「多来源中位数」，有的取「单机实测最高值」，混着用。

**修复**：写死规则 —— **优先取同一台机器的完整实测；没有的话取多来源中位数，并在 `cb23Source` 注明「中位数」；单机值必须注明机型。**

### 问题三：9 颗 CPU 的 R23 无法溯源

这些数在数据重建前就存在，来源不可考。

**修复**：逐颗重查。Game 本的 9955HX / 255HX / 251HX 优先。

## 8. 给用户的核查方法

不想信我的话，可以这样验证任意一条：

1. 打开 `data/prices.json`，找机型的 `cb23` 或 `gb6`
2. 看 `cb23Source` 字段（已加的才有）
3. 到 cpu-monkey.com 搜该 CPU，对比数字
4. 价格看 `priceNote`，里面写了具体 SKU 和优惠构成

**最该自己核的**：任何你准备基于它做购买决定的机型的价格。因为价格变化最快，而跑分相对稳定。
